# data-engineer-test
# Тестовое задание: Data Engineer

Решение включает в себя полную цепочку обработки данных: от генерации до статистического анализа.

## 🛠 Технологический стек
* **Python**: Pandas, Numpy, Scipy, Seaborn.
* **Параллелизация**: Использование `ProcessPoolExecutor` для ускорения обработки.
* **Big Data стандарты**: Хранение данных в сжатом формате `.csv.gz`.

## 📈 Что реализовано:
1. **Генерация данных**: Создан датасет (около 1 млн строк) с временными метками, числовыми и строковыми значениями + 10% дубликатов.
2. **Оптимизированный процессинг**: 
   - Параллельное чтение чанками.
   - Очистка данных (удаление NA, дедупликация).
   - Векторизованная обработка строк (регулярные выражения).
   - Фильтрация по временным интервалам.
3. **Аналитика**: 
   - Агрегация метрик по часам (уникальные значения, среднее, медиана).
   - Визуализация частотности символов по позициям (Heatmap).
   - Расчет 95% доверительного интервала.
4. **Статистика (Доп. задания)**: 
   - Сравнение групп (ANOVA).
   - Оценка вероятности успеха прототипов (Байесовский подход и правило Лапласа).

## 📁 Структура проекта
* `solution.ipynb` — код решения с комментариями.
* `large_dataset.csv.gz` — сжатый датасет для тестов.
* `requirements.txt` — список необходимых библиотек.
